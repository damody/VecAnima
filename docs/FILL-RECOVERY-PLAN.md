# 筆觸移除後的乾淨填色：實作與驗證計畫

使用者的放大圖證實上一輪分層仍有殘影。本輪目標是完整處理當前填色污染問題，不能以縮小顯示、隱藏深色或測試數量代替目視驗證。

1. 分離筆觸幾何寬度與來源完整污染範圍；半高寬用於筆觸曲線，完整剖面／來源混色證據用於移除。
2. 重建底色時排除受污染的近鄰，使用筆觸兩側乾淨表面及區域歸屬，避免複製暗邊或跨區混色。
3. 評估本地 AniLines basic／detail 模型，保留官方來源、授權及 SHA256；模型只可提供邊界／線條證據，不能把預測當作顏色或線寬真值。正式整合如採用，必須由 Rust CLI 原生執行並驗證模型內容快取身分。
4. 加入寬淡邊、不同底色、交界／junction、真實陰影、深色色塊與漸層的回歸；檢查實際填色 SVG 和完整重建。
5. 重算 Isekai 不同場景，實際放大對照原圖、僅填色、僅筆觸與合成圖。儲存圖像及測量，檢查續跑一致性，更新播放器和錯誤紀錄。

完成標準：已知殘影須在新的填色結果中消除且真實色塊／陰影保留；核心修正有回歸；CLI、SVG、播放器一致；不能宣稱不可驗證的所有動畫語意完美分離。全專案長片效能及論文完整驗收保持獨立追蹤。

## 本輪完成記錄

上述 1–5 項已實作並完成當前功能檢查。正式輸出 output/verified-clean-layers 與 output/verified-clean-layers-scene2，皆 640×360／3 幀；verified-clean-layers-scene3 為 40 秒處不同角色／柔光的 1 幀。41 Rust／27 Python／嚴格 Clippy，含來源淡邊、孤立混色 donor、連通殘線、真實窄陰影、漸層／幻線、弱線連通、相鄰陰影線寬、AI 參考推論及模型身分回歸；21 資產續跑 SHA256 一致。模型及工具已下載至 third_party，原生程式使用本地 ONNX。
