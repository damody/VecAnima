## 執行順序與功能契約

1. **M3 筆觸**：局部對比／多尺度導數找候選，法線雙側剖面排除大片深色填色；自行 thinning 與曲線圖，保留端點、分岔、閉環。估計次像素中心、左右獨立線寬、局部顏色與信心；以受誤差約束的三次 Bézier 表示中心與外輪廓。輸出原生筆觸模型及封閉填色 SVG。基準模式保留供消融。
2. **M4 幾何**：定義有限座標及退化輸入契約，自行 orientation／incircle、簡單多邊形三角化、增量 Delaunay、約束邊恢復、洞及外部剔除。共享邊界只儲存一次；不能吞掉失敗約束。以線性光頂點顏色及誤差導向細化建立網格，保留節點／誤差預算。原生網格渲染與 SVG 近似分別量測。
3. **M5 時間**：切鏡分段、相機運動及局部對應，前後一致性與低信心重新建立。追蹤記錄 birth/death/split/merge/occlusion；時間濾波以運動補償殘差決定，避免抹去眨眼和嘴型。
4. **M6 輸入／播放**：單張、序列及影片使用相同核心；版本化原生格式、網格 WebGL 播放器、影音／縮放／逐幀／原片對照與物件檢視。切換演算法參數可以重跑，無特定素材分支。
5. **M7 長片／重跑**：分階段可校驗快取、來源／設定指紋、原子狀態與斷點續跑； bounded memory、按鏡頭工作、限制中間資料量。實際 profile 後調整熱點。
6. **完整驗收**：合成拓撲／線寬／顏色／幾何／運動／切鏡／VFR／失敗恢復；Isekai 多內容短片及全片；獨立渲染、品質／資料量／耗時／記憶體／時間穩定量測；離線重建與使用文件。未達標項目修正後再驗收，所有限制如實記錄。

- 新模型先在型別、資料格式與渲染閉環中實作，再接入 CLI；不只輸出沒有參與重建的診斷資料。
- 數值／幾何失敗明確回報，不能以丟掉區域或偷偷跨越約束掩蓋。
- 設定與信心隨輸出保存；基準與改善模型並存，避免把實驗參數當作普遍常數。
- 每個階段記錄實際完成狀態；舊基準的通過不算新模型驗證。

## 使用者目視修正：連續筆觸與平滑共享邊界（優先於長片驗收）

使用者指出目前仍像像素描邊，且筆觸節點顏色沒有參與連續重建。先暫緩最終驗收，依以下順序直接實作：

1. 區分像素骨架階梯與真實尖角：以多尺度弧長方向判斷尖角，受位移限制的局部平滑，並在遞迴 Bézier 拆分時共用接線方向。閉環保持接縫連續。
2. 節點正式保存平滑後中心、弧長、左右線寬及線性光顏色；線寬／顏色以保形三次內插連續評估。觀測樣本保留，不能只保存整條平均色。
3. 依曲線切線及連續線寬生成可變寬彩色 ribbon，原生／SVG／播放器均使用節點顏色。裁切也使用平滑曲線，避免像素格裁切再次破壞外觀。
4. 色塊邊界建立一次共享曲線，兩側共用；CDT 使用誤差受限的曲線離散，而不是硬保留所有像素拐角。檢查相交、孔洞、窄區域與 junction，失敗時縮小平滑位移並記錄，不能吞掉約束。
5. 以斜線／圓弧／變線寬／變色線／平滑色塊合成素材及 Isekai 放大畫面做當前功能檢查，確認資料與實際渲染一致，再回到長片與最終驗收。

## 平滑模型實作與當前驗證

- `curves.rs`：受限平滑、多尺度角點判別、Bézier 遞迴共用切線、閉環接縫；展平同時檢查控制多邊形長度，保留共線回折的極值。
- `spline.rs`：左右線寬與線性 RGB 各自使用保形三次 Hermite/PCHIP，避免負線寬及顏色過衝；每個正式節點保存中心、弧長、左右線寬、顏色及信心，實際參與 ribbon 重建。
- `strokes.rs`：f64 多尺度亮度谷檢測、剖面線寬與變色 ribbon；相似筆觸不互相裁碎，遮擋輪廓也平滑。短粗色谷以 `--stroke-min-aspect` 留在填色層。幾何外觀可平滑，仍不宣稱每個語意筆觸都能完美辨識。
- `shared.rs`：每條色塊界面只建一條曲線，兩側反向共用；保持 junction、孔洞，局部控制柄／位移收縮解決交叉，未忽略約束。
- `mesh_fill.rs`：曲線以 0.04 工作像素誤差展平成 CDT 約束；CPU 四個子像素在線性光積分，WebGL 啟用 MSAA。SVG 以扇區外輪廓統一抗鋸齒裁切，內部不透明拼片與外側邊色延伸避免裂縫，沒有嵌入點陣圖。
- 誤差契約：`max_channel_error` 仍報全域原圖比較；`interior_max_channel_error` 與 `unmet_pixels` 單獨度量非實際不連續邊界帶的擬合。一般連續漸層不排除。平滑移動邊界可能改變原格子像素，因此不能把全域原圖色差稱作全域曲面擬合界。預算不足時 `vertex_budget_reached` 明確保留。
- 播放器保留筆觸／色塊 checkbox、SVG／原生模式；放大保持檢視中心，點擊物件顯示最近節點左右與總線寬、線性光顏色及信心。
