2026-10-08。接續既有 Rust CLI，使用 OpenCV 4.14.0／FFmpeg；不使用 CGAL，不依素材座標、角色、顏色或時間設特殊規則。錯誤統一記入 ERRORS.md。

## 順序與驗證契約

1. 筆觸連通：區分模型支撐中斷、來源剖面失效、裁切及顏色偏淡。使用有強證據錨點的弱支撐連通與沿曲線的缺失剖面恢復，禁止在平色／線性漸層或不相關端點之間硬接。
2. 觀測與重建：中心、法線、來源顏色及左右線寬分別估計；模型只提供位置／拓撲先驗，無效的原圖觀測不能當真值。低信心／推估標記保存；節點參數必須實際參與 Rust、SVG 及播放器渲染。
3. 填色通用性：柔光、壓縮噪聲、跨色交界、真實窄陰影及大片深色保留。查清色盤界面與實際來源不連續的差別，不能以放大去線遮罩或加顏色數掩蓋。
4. 時間與資料量：檢查多幀輪廓／區域追蹤、切鏡、遮擋、記憶體及 SVG 成本；將實際誤差／預算／恢復事件寫入報告，不只記平均 PSNR。
5. 整合後驗收：合成反例、Isekai 不同場景及全時長處理、原生／SVG 獨立渲染、checkbox、續跑一致性、影音與離線重建。失敗先修核心再重測受影響項目。
