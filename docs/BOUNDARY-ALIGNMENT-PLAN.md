# 色塊形狀對齊修正計畫

2026-10-08，依使用者提供 full-crop.png。先暫停全片驗收，保留未完成輸出；以最新版原圖／純填色／完整重建與未裁切 RGB 差分定位，不拿平滑或低全域 MAE 取代形狀驗證。

1. 檢查去線未知區與 clean donor 指派：最近空間距離不等同原始色塊邊界，特別是兩側 core 距離不對稱、尖角及窄陰影。
2. 來源約束補色：在局部範圍比較各色彩 donor，原始 RGB 與筆觸色的混合殘差提供資料項；沿筆觸中心／法線保持左右側約束，深色完全遮蔽處才使用空間先驗。乾淨來源觀測保留，不讓安全帶吞掉形狀。
3. 調和求解只做各色塊內連續顏色恢復，不能以 Voronoi 分區決定真實形狀。所有參數按工作像素／來源證據，沒有角色座標或顏色特判。
4. 合成不對稱去線帶、曲線／尖角／窄真陰影，按來源已知底色量測分區 IoU／邊界偏移與重合成誤差；原生與 SVG 都驗證。再重算 Isekai 三場景，比較修正前後原圖差分／邊界疊圖與 fill-only。
5. 測試及局部形狀確認後，再以新指紋輸出完成全片整合驗收。所有失敗追加 ERRORS.md。
