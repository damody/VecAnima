## 完成的檢查

- 43 個 Rust 測試、28 個 Python 驗證（9 個原生 CLI）、嚴格 Clippy 通過。
- 已知平移的變色曲線：連續三幀保持同一筆觸 ID，估計中心平移誤差小於 0.75 工作像素，線寬變化小於 0.3；切鏡不沿用舊 ID。
- 弱來源對比 2／模型弱證據 0.1 的長線連通；平色與線性漸層幻線拒絕。
- 淡邊／donor 暗斑／連通殘線、不同底色、真實窄陰影、深色色塊、AI 原生對照、Unicode 路徑、模型內容快取身分回歸。
- 線性光調和恢復的漸層誤差不超過 1 灰階，硬陰影逐像素不滲色；色盤分區不硬切連續 ramp。
- SVG 色塊與筆觸共用連續漸層，預設色差界限 2；獨立 resvg／原生渲染回歸。
- 本機實際 SVG 三倍放大，筆觸開／關畫面保存於 output/general-quality-svg；不同角色／柔光畫面保存於 general-quality-svg-scene3。
- 第一場景 21 個資產續跑前後 SHA256 一致，3 次向量快取命中；含音訊 MP4 的實際時長吻合。

## 全時長檢查狀態

output/acceptance-general-320：91.01 秒選取、2180 個來源影格，320×180、同一 AI／mesh／temporal 核心；因使用者指出色塊形狀偏移，已停止並保留 incomplete；見 BOUNDARY-ALIGNMENT-PLAN.md 及 E052。不可拿本目錄作新版本驗收。只有 status.json 為 complete、preview-probe 與獨立 audit 通過後才標記完成。

```powershell
.venv/Scripts/python.exe scripts/verify_project.py output/acceptance-general-320 --minimum-duration 90 --model third_party/anilines/basic.onnx
```

scripts/verify_project.py 逐資產雜湊、檢查 SVG 不嵌入點陣圖、模型 SHA256、正線寬／有限數值、三角形索引、網格預算與調和收斂；逐幀檢查 PTS／duration、獨立追蹤 ID、切鏡／相機補償殘差及影音實際時長。幾何僅保留兩個資產的快取；時間統計是演算法自身關聯的描述，已知運動合成案例才提供外部真值。

## 資料量與已知限制

降低 SVG 色差及保留純向量會增加資料量。本次 3 幀的合成 SVG 已約 136／129／205 MB，包含分層 SVG、JSON、網格後更多；不能宣稱即時處理或比來源影片更小。原生 WebGL 使用 binary f32 緩衝以減少解析成本，SVG 作交換／放大檢查。初版不承諾壓縮比，見 PLAN.md 固定決策。

所有方法按來源尺度／證據運行，沒有 Isekai 角色、顏色、座標或時間特判。語意陰影／筆觸歧義、完整論文逐項重現、HDR／多音軌選擇不是本次檢查能保證的能力；不得把工具鏈通過寫成任意動畫品質完美。
